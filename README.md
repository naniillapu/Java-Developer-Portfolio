# Java Developer Portfolio — Venkata Rajeswararao Ilapa

A responsive dark-theme portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, dark theme, cards, and typography
- `script.js` — mobile navigation, active section highlighting, copy-email interaction

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a more realistic local-server preview, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Before publishing
- Confirm the exact wording of your project contributions and certifications.
- Add your real LinkedIn and GitHub profile URLs if you want them displayed.
- Add a PDF resume file and link it to a download button if desired. This version intentionally does not fabricate a resume file.
- Consider adding credential verification links for certifications.
- Do not publish confidential client information, internal screenshots, source code, URLs, or architecture.

## Publish free
You can publish this static website with GitHub Pages, Netlify, or Cloudflare Pages. Upload the three site files and follow the hosting provider's deployment steps.

## Notes
The website's JavaScript is only used for interface interactions; JavaScript is not listed as one of the portfolio owner's professional skills.
